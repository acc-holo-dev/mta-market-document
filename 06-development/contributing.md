# Как вносить изменения

## Где что править

| Изменение | Репозиторий |
|---|---|
| API, UI, Prisma | mta-market-site |
| C++ модуль, SDK | mta-market-module |
| Статус, ADR, протокол, API-таблица | **этот** репозиторий, тем же смыслом что и код |

Не копировать документы в `site/document/` или корень SDK.

## Документы

- Один канон, язык русский.
- Статус = код. Не писать «production-ready» без гейта.
- Новый эндпоинт / сущность / ADR — файл в том же PR что код (или сразу следом).
- Session-отчёты и аудиты в git не класть.

## Код

- Без `--no-verify`.
- Деньги и DRM: без dev-байпаса в production.
- Секреты не коммитить.

Поведение в сообществе: без оскорблений, без слива чужих ключей и артефактов покупателей.
