# Глоссарий

| Термин | Значение |
|---|---|
| Resource | Карточка товара, не файл |
| Version | Релиз с blob и checksum |
| Order | Заказ/корзина |
| Payment | Движение денег у провайдера |
| Purchase | Право на ресурс после оплаты |
| License | Право запускать |
| Installation | Конкретная установка с ключом |
| Lease | Подписанный допуск на срок (цель v2) |
| DEK | Ключ шифрования блоба скрипта |
| Spike | Проверка гипотезы, не продукт |
| CUID | Строковый id Prisma |
| Копейки | Единица денег в БД |
| Guard | Будущий DRM-слой поверх SDK |
| SDK | C++ обёртка ABI MTA |
