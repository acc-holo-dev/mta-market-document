# Готовность к продакшену

Каждый гейт: **нет / частично / да**. «Да» только если есть код и проверка. Документ не заменяет тесты.

## Безопасность

| ID | Требование | Сейчас |
|---|---|---|
| S1 | ID домена — String CUID | частично (см. статус: Review/ledger FK) |
| S2 | Dev-обход оплаты недоступен в production | да (`simulate` за NODE_ENV) |
| S3 | Вебхук провайдера + идемпотентность | частично (таблица событий есть; полный прод-контур не верифицирован) |
| S4 | Скачивание только по праву (signed URL) | частично |
| S5 | Активация DRM проверяет владельца покупки | да |
| S6 | Продавец не публикует сам в PUBLISHED | нужно держать в коде модерации |
| S7 | Refresh не в localStorage/URL | частично (cookies на API) |
| S8 | Хеш refresh + ротация | да |
| S9 | Старт без секретов в production падает | да |
| S10 | Валидация входа на всех эндпоинтах | частично |
| S11 | Песочница загрузок | нет |
| S12 | Observability | нет |
| S13 | Атомарный ledger | нет |
| S14 | DRM v2 (асимметрия, lease) | нет |
| S15 | State machine сущностей | частично |
| S16 | Rate limit | частично (Redis, не везде per-user) |
