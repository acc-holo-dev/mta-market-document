# IDEAS — идеи развития MTA Market

Сводный список идей, перенесённых из старой документации (преимущественно
`unique-features`, `detail-plan`, `roadmap`, `production-readiness` старой структуры).

**Наличие идеи здесь не означает обязательство её реализовать.** Идея становится
частью работы только через явный выбор в очередном Development Plan.

---

## 1. Доверие и конверсия покупателя

- **Live Demo («попробуй до покупки»)** — публичный MTA-сервер площадки, демо-режим
  по разовому коду, лицензия с TTL ~15 мин, бейдж «доступен тест-драйв» на карточке.
  Реализация: headless MTA-серверы в Docker, слот-пул.
- **Депозит доверия продавца** — заморозка части будущих выплат в «гарант»;
  бейдж «гарантия возврата» в карточке; выплата покупателю из депозита при обмане.
- **Здоровье лицензии как витрина** — публичные агрегаты активных установок
  («137 активных серверов»), только агрегаты, без IP/hostname/гео (152-ФЗ).

## 2. Работа с моделями и ассетами

- **Asset Studio** — 3D-просмотр DFF/TXD в браузере (Three.js; база: rwtool,
  rw-parser, DFF-Loader, dffinity), автогенерация постеров/turntable-GIF,
  валидация ассетов, автостатистика (полигоны, LOD, коллизии), просмотр .map,
  слайдер «до/после», скин-вьюер с анимациями, кастомные колорвеи.
- Оговорка: модели нельзя защитить шифрованием (движок читает их открыто) —
  для моделей защита = водяные знаки + Leak Radar (ниже).

## 3. Защита и форензика

- **Watermark + Leak Radar** — уникальный ID сборки в каждой проданной копии;
  краулер по VK/Telegram/GitHub/форумам; результат — forensic scoring
  («confidence: 97%»), не автоматический вердикт; кнопка «Report leak»
  с премией репортёру на баланс.
- **Пассивный аудит совместимости** — heartbeat присылает версию MTA/ОС/ресурсы;
  бейдж «протестирован на MTA X, Ubuntu/Windows»; при выходе нового MTA — авто-прогон
  по платным ресурсам и уведомление продавцам.

## 4. Продавцу

- **Seller analytics** уровня ecommerce: просмотры → конверсия, источники,
  анонимная гео/сервер-телеметрия, повторные покупки, доход по месяцам.
- **Seller API + webhooks** — интеграция витрины продавца с его Discord.
- **Планировщик релизов** — draft → release по расписанию.
- **A/B карточки товара** — 2 заголовка/обложки со статистикой кликов.
- **Инфлюенсер/реферальные промокоды** по ссылкам ютуберов.
- Upload-валидация в браузере до загрузки (структура meta.xml, размер, зависимости).
- Экспорт продаж в CSV.

## 5. Покупательский UX

- Поиск с опечатками (PostgreSQL FTS → Meilisearch), фильтры в URL.
- Сравнение ресурсов рядом (diff-таблица); «Мой сервер» — фильтр совместимости.
- История версий как GitHub releases; уведомление «вышло обновление купленного» →
  one-click update (безопасный апдейт с backup/rollback — см. MTA Market Manager).
- **Bundles** — шаблонные пакеты для новичков («Открой DM-сервер», −30%).
- **Wishlist**, сохранённые фильтры.

## 6. Монетизация и платежи

- **Subscriptions** — рекуррентные платежи ЮKassa.
- Пополнение баланса (после него — баланс как способ оплаты покупок).
- Несколько платёжных провайдеров (интерфейс провайдера уже нейтральный).
- Мгновенные выплаты продавцам / payouts-контур.

## 7. Коммуникации

- **Чаты** покупатель ↔ продавец по заказу услуг (WebSocket) + e-mail уведомления.
- Публичная страница /status (uptime License Server).

## 8. Легитимный менеджер лицензий

- **MTA Market Manager** — небольшой официальный модуль площадки: только лицензии/
  heartbeat/обновления; ресурсы изолированы; обновления с changelog, подтверждением
  покупателя, backup предыдущей версии и rollback одной кнопкой.

## 9. Эксплуатация и зрелость (кандидаты в PLAN-002)

Из старых гейтов production-readiness, которые остаются открытыми после PLAN-001:

- Боевой контур платежей: реальный webhook ЮKassa + reconciliation на живом провайдере.
- Пополнение баланса (см. §6) и лимиты/лимиты-мониторинг.
- DRM client E2E против живого сервера; проверка Windows-исполнения модуля.
- Restore drill (бэкап/восстановление Postgres), алертинг, наблюдаемость.
- Восстановление после сбоев artifact storage (S3-контур).

## 10. Антифичи (сознательно не делаем)

- Собственный форум (Discord-сообщества уже есть).
- Скачивание открытых исходников платных скриптов.
- Мобильное приложение (адаптивного сайта достаточно).
- Ручная модерация каждого отзыва (автофильтры + жалобы).
- Собственный видео-хостинг (только embed YouTube).
- Система уровней/ачивок продавцам на старте.
