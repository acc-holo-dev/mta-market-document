# Threat model linkage (P-011)

Every major threat maps to: **Threat → security requirement → implementation
(file) → test (file/test name) → status**. Requirement IDs refer to the
implementation plan (A-00x hardening tasks, B-00x platform, C-00x commerce,
INV-nn invariants) and to the qualitative model in
[threats.md](threats.md) — that older page predates DRM v2 (its "Сейчас"
column is outdated; this table is the current linkage).

All tests cited below pass in the verified run: **222/222 tests, 21 files,
2026-09-09** (`mta-market-site`, vitest, PostgreSQL 16 + Redis 7).

## Residual risks (honest)

- Memory of a running MTA server can dump decrypted payloads — DRM is
  cost-raising, not absolute (ADR-005; see [threats.md](threats.md)).
- Logger redaction has no test; the regex list is the only guard.
- Windows key-store protection (DPAPI) is unexercised by tests.
- No automated secret-scan/dependency-scan CI gate yet (O-005 — planned).
