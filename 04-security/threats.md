# Модель угроз

Формат: кто → что хочет → как бьём → что всё равно остаётся.

| Кто | Цель | Митигация (цель) | Сейчас |
|---|---|---|---|
| Покупатель | ресурс без оплаты / раздать файл | нет complete без провайдера; blob без DEK бесполезен | simulate только в non-prod; шифр v2 нет |
| Продавец | малварь / мусор за деньги | модерация, escrow у провайдера, отзывы после покупки | модерация ручная; sandbox нет |
| Взломанный MTA-сервер | дамп ключей и plaintext | ключ только locally; 1 installation | private key на license server |
| Угон аккаунта | чужие лицензии | cookie, ротация refresh, 2FA позже | 2FA нет |
| Сеть | replay lease, фейковый license server | Ed25519 + TLS + nonce | lease нет |
| Пират | публичный слив скрипта | cost-raising, атрибуция | spike не защищает |
| Компрометация площадки | БД / S3 / CI | секреты, минимум прав, не хранить private ключи клиентов | ключи клиентов в БД |

Остаточный риск памяти процесса MTA не закрывается. Не писать в маркетинг обратное.
